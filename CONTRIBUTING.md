# Contributing

## Code of Conduct

Be constructive. Review with intent to improve. No spam or off-topic promotion.

## How to Contribute

1. Open an issue describing the problem or proposed change.
2. Keep PRs focused and minimal.
3. Include reproduction steps or rationale.
4. Do not submit secrets or credentials.

## Development

```bash
npm install
npm run dev
```

## Commit Messages

Use clear, descriptive commit messages. Prefer present tense and scoped subjects.
