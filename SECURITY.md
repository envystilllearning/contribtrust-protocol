# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you find a security issue, do not open a public issue.

Email the maintainer or use a private report on GitHub with reproduction steps, affected versions, and potential impact.

Please do not publicly disclose the vulnerability until it has been addressed.
